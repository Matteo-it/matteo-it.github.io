# 📱 Matteo Marsala - Personal Website

This is a personal website built using React.

The website is published on Github Pages using github actions.

## Getting Started

To run this project locally:

```bash
# Clone the repo
git clone git@github.com:Matteo-it/matteo-it.github.io.git

# Navigate into the project
cd matteo-it.github.io.git

# Install dependencies
npm install

# Start the development server
npm run dev
```
